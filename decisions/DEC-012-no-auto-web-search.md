## 用户原话

> 登记我描述的用户故事：2. 用户：帮我梳理论文主题；Agent：在梳理完成主题内容后并登记代办issue后，根据主题内容生成论文编写计划。论文计划中需要包含：a. 论文主题内容背景包含，定义论文所要解决的问题内容，以及问题范围。b. 论文写作大纲：定义论文写作大纲框架，规定论文中每个章节描述的内容概述。c. 文献列表：罗列本地用户已经下好的或者指定好的，或者由Agent自己通过多数据源搜索和查找并验证来源的文献，以及文献的对于这篇论文的贡献信息，包括：文献中对于用户论文问题的可引用的段落位置以及段落内容的摘要。该文献对于整篇论文研究的贡献。

## 实现取舍

1. v0.1 不做自动联网检索：不新增检索命令、不调用外部搜索 API，与 README 已声明的能力边界一致，本轮将其升级为正式决策。
2. source_type 中的 agent_retrieved 在 v0.1 降级为“Agent 依据用户粘贴/提供的检索结果文本整理”；verification.basis 必须记录用户提供的出处文本位置，无出处文本不得登记为该来源类型。
3. 真实多数据源检索列为后续版本候选能力。
4. US-002 验收相应分阶段：v0.1 验收 local 与 user_specified 两类及降级后的 agent_retrieved，真实检索部分待后续版本核验。

## 影响范围

US-002 文献来源三类定义中 agent_retrieved 的 v0.1 语义与验收拆分；references 条目 source_type 与 verification.basis 的填写约束；后续版本的候选能力清单。
