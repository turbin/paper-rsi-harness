## 用户原话

> 登记我描述的用户故事：3. 用户：帮我梳理论文主题；Agent还要在论文写作大纲各个章节内容中定义问题描述方式，是文字描述、图例描述、表格描述等。如果是图例描述要描述好如何构建这个图，并标注好图号。如果是表格描述，要将表格描述好并标注好表号。然后将图号和表号要形成可索引信息。

## 实现取舍

1. 图表索引文件为 `writing/outline/figure-table-index.md`，内容为 Markdown 表：图/表号 | 名称 | 所在章节 | 说明位置 | 构建/结构说明摘要。
2. 编号规则以 formatting_guidelines 登记的用户规范为准；规范未明确编号格式时，按 Skill 机制登记 notes/issues/ 待澄清，禁止默认采用“图 1-1”式编号。
3. v0.1 唯一性校验由 Skill 步骤人工核对 + 索引文件本身的约束保证；控制器层自动校验留待编号规则明确后实现。
4. 索引是论文内容文件，不复用工程 index.md 的 paper-index 标记块格式。

## 影响范围

writing/outline/ 目录产出；US-003 图表编号索引的落盘格式与编号来源；DEC-007 第 2 条与 DEC-013 规范登记的衔接；后续控制器校验的实现时机。
