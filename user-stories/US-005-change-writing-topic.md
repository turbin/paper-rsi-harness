## 触发场景

## Agent 行为

1. 将当前目录（论文工作区）下所有相关文件，包括决策文件等，提交存放到 git 中。
2. 询问用户是否需要清空当前工作区、重新开始写作。
3. 用户回答“是”时，新建新的分支并切换到该分支下。
4. 将当前目录恢复到工作区的初始状态。
5. 清空所有决策信息和 issue 信息，以及之前版本在写作过程中产生的任何文件和信息。
6. 重新使用苏格拉底式提问流程 skill（paper-spec-socratic）帮助用户梳理写作思路。

## 验收条件

- 清空工作区之前，当前版本所有相关文件（含决策文件）已提交到 git，旧版本可回溯。
- Agent 在清空之前先询问用户，用户确认后才执行清空；未经确认不执行。
- 用户确认后，新分支已创建并切换，清空动作发生在该新分支上；新分支按 `feature-主题摘要信息` 命名。
- 工作区恢复到初始状态（见“范围与现有实现”的定义）：决策信息、issue 信息及之前版本写作过程中产生的文件和信息均被清除。
- 清空完成后，Agent 启动苏格拉底式提问流程帮助用户梳理新主题的写作思路。
- 用户回答“否”时，本次按针对上一版本的迭代处理；用户要求时也可以新建分支后继续执行。
