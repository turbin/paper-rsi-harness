> 登记我描述的用户故事：3. 用户：帮我梳理论文主题；Agent还要在论文写作大纲各个章节内容中定义问题描述方式，是文字描述、图例描述、表格描述等。如果是图例描述要描述好如何构建这个图，并标注好图号。如果是表格描述，要将表格描述好并标注好表号。然后将图号和表号要形成可索引信息。

## 用户故事

作为正在规划论文的用户，我希望 Agent 在论文写作大纲中明确各章节内容的问题描述方式，并为拟使用的图和表提供构建或内容说明、编号及索引信息，使后续写作可以按计划组织文字和图表，并通过编号找到对应内容。

## 触发场景

用户：“帮我梳理论文主题。”Agent 按 US-002 生成或完善论文写作大纲时，补充本故事要求。

## Agent 行为

1. 在各章节内容中明确问题采用文字、图例、表格等何种方式描述；同一内容需要多种方式时，分别说明其职责。
2. 采用文字描述时，说明需要表达的问题内容与叙述方式。
3. 采用图例描述时，说明如何构建图，并在对应章节内容中标注图号。
4. 采用表格描述时，说明表格内容与结构，并在对应章节内容中标注表号。
5. 将图号与表号整理为可索引信息，可以通过编号找到对应章节内容及图表说明。

## 图表说明与索引的信息要求

| 对象 | 说明要求 |
|---|---|
| 图 | 说明表达的问题、构建方式及必要组成。例如流程图的节点与连线、关系图的要素与关系、数据图的坐标轴与指标；示例不限定图的类型 |
| 表 | 说明表达的问题、表格结构和内容。例如行列含义、字段、指标或比较维度；涉及数值时说明相应单位与口径 |
| 图号/表号索引 | 至少能由编号定位对应章节和图表说明；编号、名称或摘要、所在章节/小节及说明位置可用于实现这种关联 |

上述信息是对“描述好”和“可索引”的验收解释，不代表用户指定了固定文件格式。计划中的图表可以先有说明与编号，最终图表尚未生成时不虚构成品文件位置。

## 验收条件

- 大纲的各章节内容均明确问题描述方式，能够看出哪些内容用文字、哪些用图或表表达。
- 每个计划使用的图有构建说明和图号，说明足以指导后续绘制。
- 每个计划使用的表有内容与结构说明和表号，说明足以指导后续编制。
- 图号、表号形成可检索的索引条目，通过编号能够定位对应章节及其说明。
- 章节中的图表编号与索引一致；每个编号在其图或表的编号体系中能唯一定位对象，不存在重复指向不同对象或找不到说明的编号。
- 图表的编号和格式与用户指定的论文规范文件中的描述一致（关联 US-004）。
